Todo lo que se puede cambiar esta dentro de main, o al menos cambiar de forma segura. 
Cualquier cosa cada clase representa o un elemento grafico, una pantalla distinta o un proceso.
El archivo config.py tiene guardada la ip global de servidor principal, esta ip esta puenteada con Ngrok por seguridad.
El archivo local.json tiene guardada la info de la secion local iniciada, al abir el programa se revisa que la id y las creedenciales coincidan para evitar seciones incorrectas, aca no se guarda la contraseña btw.
Las contraseñas estan cifradas dentro de la base de datos de manera permanente y ninguna persona puede acceder a ellas, ni siquiera a las bases encriptadas.
Los datos del usuario se recopilan y al probar esta beta puede que se recopilen datos del usuario o programador

Al leer esto y trabajar en este proyecto estoy aceptando que mis datos pueden ser recopilados, almacenados y usados con fines comerciales

Se asume que se aceptan los terminos y condiciones al descarcar, modificar o ejecutar alguno de los archivos del proyecto
